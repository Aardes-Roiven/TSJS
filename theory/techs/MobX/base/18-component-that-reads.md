# The component that reads the observable must be wrapped in observer

Детализация п. 18 уровня «base», MobX. Оглавление: [index.md](./index.md).

Конспект: сначала о чём речь и зачем это нужно на этом уровне, потом устройство, пример, ловушка и короткая формулировка, с которой тему можно закрыть.

#### О чём речь

`observer` размечает только ту функцию, которую в него передали (этот уровень, п. 17). Поле, прочитанное в рендере ребёнка, записывается в список ребёнка, и только если обёрнут ребёнок. Обёрнутый родитель, который сам поле не читает, из-за `add` заново не выполняется. Необёрнутый ребёнок тогда тоже остаётся на первом числе. Заказ уже новый, на экране старый текст. Обёртка родителя на ребёнка не распространяется.

---

#### Модель

React вызывает каждую функцию компонента отдельно. Проход диаграммы — это один такой вызов. Чтения ребёнка происходят в вызове ребёнка, не в вызове родителя. Родитель в своём проходе создал элемент `<Amount order={order} />` и в `amount` не заглянул. Список родителя этого поля не содержит.

Ребёнок без `observer` — обычный рендер React. Его чтения в список MobX не попадают. Заново его вызовут, когда родитель нарисуется снова. Родитель из-за `amount` не рисуется. Цепочка стоит.

---

#### Ребёнок, который читает поле

Функция, в чьей разметке стоит `order.amount`, сама передаётся в `observer`. Её рендер заглядывает в поле. `add` выполняет эту функцию снова, даже если родитель поле не читал и сам не обёрнут. Родитель может быть обычным компонентом, который только передал ссылку на заказ.

Несколько таких детей независимы. Компонент, который читает `amount`, обновляется от `add`. Сосед, который читает `label` и не читает `amount`, от `add` не обновляется.

#### Родитель не подсматривает в рендер ребёнка

`<Amount order={order} />` в обёрнутом родителе читает поле `order` только если родитель сам написал `order.amount`. Создание элемента поле `amount` не читает. Обернуть родителя и оставить `Amount` обычной функцией значит, что чтение `amount` оказалось вне всякого прохода MobX.

Колбэк, который рисует разметку уже внутри чужого компонента, — отдельный проход. Его оборачивают так же, но место обёртки другое: advanced, п. 41.

---

#### Пример

```jsx
import { makeAutoObservable } from "mobx"
import { observer } from "mobx-react-lite"

const order = makeAutoObservable({
    amount: 1,
    add() {
        this.amount += 1
    }
})

const Amount = observer(function Amount({ order }) {
    return <span>{order.amount}</span>
})

function Page() {
    return <Amount order={order} />
}

// первый показ Amount: текст "1"
order.add()
// следующий показ Amount: текст "2"
```

`Page` в `observer` не нуждается: она поле не читает. `Amount` читает `order.amount` в своём рендере и обёрнут. `add` выполняет `Amount` снова. Текст становится `"2"`.

---

#### Ловушка

Обёрнут родитель, а читает необёрнутый ребёнок. Экран остаётся на `"1"`.

```jsx
import { makeAutoObservable } from "mobx"
import { observer } from "mobx-react-lite"

const order = makeAutoObservable({
    amount: 1,
    add() {
        this.amount += 1
    }
})

function Amount({ order }) {
    return <span>{order.amount}</span>
}

const Page = observer(function Page() {
    return <Amount order={order} />
})

// первый показ: текст "1"
order.add()
// показ тот же: текст "1"
// order.amount равен 2
```

Проход `Page` в `amount` не заглядывает. Проход `Amount` в список MobX не пишется. `add` ни одну из функций снова не вызывает. Перенесите `observer` на `Amount`, туда, где в разметке стоит `order.amount`.

---

#### Сводка

| Кто читает `order.amount` во время рендера | Что нужно для нового текста после `add` |
|---|---|
| Ребёнок | `observer` вокруг ребёнка |
| Родитель, который передаёт число дальше | `observer` вокруг родителя; ребёнок может быть обычным (этот уровень, п. 19) |
| Ребёнок, а обёрнут только родитель | Текст остаётся первым, поле уже новое |

Оборачивайте функцию, в чьём теле поле превращается в текст. Обёртку соседа или родителя этой функции не зачитывайте.

#### Граница инструмента

Границу прохода задаёт React: одна функция компонента — один вызов. MobX записывает чтения только у вызова, обёрнутого в `observer`. Необёрнутый рендер для MobX — обычная функция JavaScript.

#### Чем закрыть тему

Соберите родителя без чтения `amount` и ребёнка, который выводит `order.amount`. Оберните ребёнка, вызовите `add` и проверьте, что текст стал `"2"`. Снимите `observer` с ребёнка, наденьте его на родителя, вызовите `add` и проверьте, что текст остался `"1"`, а `order.amount` равен `2`.

Уровень base по оглавлению закончен.
