# The disposer returned by autorun

Детализация п. 10 уровня «base», MobX. Оглавление: [index.md](./index.md).

Конспект: сначала о чём речь и зачем это нужно на этом уровне, потом устройство, пример, ловушка и короткая формулировка, с которой тему можно закрыть.

#### О чём речь

`autorun` возвращает функцию. Вызовите её, чтобы остановить эту реакцию. Пока вы её не вызвали, эффект продолжает выполняться после поздних action, в том числе после того, как вернулась функция, создавшая `autorun`. Оставшаяся реакция всё ещё читает заказ, поэтому лог растёт, а заказ остаётся достижимым. У каждого `autorun` должен быть хозяин, который его останавливает: конец теста, закрытие экрана. Что эффект выполняет до этой остановки — этот уровень, п. 9.

---

#### Модель

Диаграмма висит, пока её не снимете. Снять — значит вызвать функцию, которую вернул `autorun`. Поздние правки эту диаграмму не перерисовывают. Другие диаграммы остаются. Поля тоже остаются: остановка реакции объект не сбрасывает.

В примерах функция названа `stop`. Это не импорт. Это возврат именно этого вызова `autorun`.

---

#### stop заканчивает только эту реакцию

`stop()` снимает эту реакцию. Поздний `order.add()` по-прежнему меняет `amount`. Этот лог не растёт. Другой `autorun`, который вы не остановили, новое количество всё ещё пишет.

Верните `stop` из функции, которая начала наблюдение, и пусть вызывающий вызовет его, когда наблюдение кончилось. Если эта функция возвращает только заказ, наблюдение продолжается.

#### Второй вызов ничего не делает

Повторный `stop()` не бросает ошибку и не останавливает другой `autorun`. Первый вызов уже снял эту реакцию. Код разборки может вызвать `stop`, даже если более ранний путь уже его вызвал.

#### Эффект не может вернуть stop

MobX игнорирует значение, возвращённое из функции, которую вы передали (этот уровень, п. 9). `stop` существует только как возврат `autorun(...)`. Функция очистки, возвращённая из эффекта, никогда не вызывается и реакцию не заканчивает.

---

#### Пример

```javascript
import { makeAutoObservable, autorun } from "mobx"
const order = makeAutoObservable({
    amount: 0,
    add() {
        this.amount += 1
    }
})
function watch(order) {
    const log = []
    const stop = autorun(() => {
        log.push(order.amount)
    })
    return { log, stop }
}
const first = watch(order)
first.stop()
order.add()
// first.log равен [0]
// order.amount равен 1
const second = watch(order)
order.add()
// second.log равен [1, 2]
// first.log по-прежнему [0]
```

`first.stop()` выполняется до первого `add`, поэтому `first.log` остаётся `[0]`, пока `amount` становится `1`. `second` сразу записывает текущую `1`, затем `2` после следующего `add`. Остановка первого наблюдения оставила второе наблюдение и поле в покое.

---

#### Ловушка

Выброшенный возврат оставляет реакцию живой после возврата `start`.

```javascript
import { makeAutoObservable, autorun } from "mobx"
const log = []
function start() {
    const order = makeAutoObservable({
        amount: 0,
        add() {
            this.amount += 1
        }
    })
    autorun(() => {
        log.push(order.amount)
    })
    return order
}
const order = start()
order.add()
// log равен [0, 1]
```

`start` вернул заказ и выбросил `stop`. `add` по-прежнему дописывает в `log`. Верните `{ order, stop }` и вызовите `stop()` до того `add`, который не должен попасть в лог.

---

#### Сводка

Сохраните функцию, которую возвращает `autorun`, и вызовите её, когда этот побочный эффект должен закончиться. Объект остаётся. Другие реакции остаются. Второй вызов той же функции ничего не делает. Хозяин наблюдения — хозяин `stop`: разборка теста или вызывающий, который закрыл экран.

#### Граница инструмента

`stop` — это MobX. Это не сборка мусора. Живая реакция продолжает читать объект, поэтому объект остаётся достижимым. После `stop()`, если объект больше никто не держит, обычная сборка мусора может его забрать.

#### Чем закрыть тему

Запустите `autorun`, вызовите функцию, которую он вернул, затем измените поле. Проверьте, что лог остался на месте, а поле изменилось. Запустите другой `autorun`, не останавливая его, снова измените поле и проверьте, что вырос только второй лог.

Уровень base по оглавлению закончен.
