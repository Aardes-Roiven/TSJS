# this when a method is used as an event handler

Детализация п. 8 уровня «base», MobX. Оглавление: [index.md](./index.md).

Конспект: сначала о чём речь и зачем это нужно на этом уровне, потом устройство, пример, ловушка и короткая формулировка, с которой тему можно закрыть.

#### О чём речь

`order.add()` меняет заказ, потому что вызов ставит `this` в `order`. Кнопка обычно получает одну функцию и вызывает `handler()`. Метод, записанный как `add() { this.amount += 1 }`, тогда видит `this` как `undefined` и бросает ошибку. Поле не меняется. Клик работает, если обработчик вызывает `order.add()` или если `add` — стрелочная функция, которая уже знает экземпляр. Привязка каждого метода за вас — advanced, п. 29.

---

#### Модель

Вызов метода — это «попроси этот объект прибавить». Объект — это `this` внутри метода. `const handler = order.add` копирует функцию и оставляет объект позади. Поздний вызов `handler()` не имеет объекта перед собой. JavaScript не помнит, что функцию взяли с `order`.

Стрелочная функция, лежащая на экземпляре, помнит. Она использует экземпляр как `this`. Передача этой функции всё равно прибавляет к тому же заказу.

---

#### Метод, оторванный от объекта

`add() { ... }` лежит на прототипе. `order.add(1)` — вызов метода, и `this` равен `order`. `const handler = order.add`, а затем `handler()` — обычный вызов. В модуле или классе `this` равен `undefined`, и `this.amount` бросает `TypeError`. Поле остаётся прежним. MobX присваивания не видит. Кнопка, таймер или любой другой колбэк, который вызывает `handler()`, попадает в ту же ошибку.

#### Обёртка возвращает объект

`() => order.add()` — новая функция. Когда кнопка её вызывает, тело выполняет `order.add()`, а это вызов метода. `this` внутри `add` равен `order`. Обёртка замыкается на переменную `order`. Обёртка, собранная для другого заказа, обновляет другой заказ.

#### Стрелочное поле хранит экземпляр

`add = () => { this.amount += 1 }` создаётся с `this`, закреплённым за экземпляром. `makeAutoObservable` по-прежнему считает его action (этот уровень, п. 2). `const handler = order.add`, а затем `handler()` обновляют `order.amount`. Стрелочное поле берите, когда функцию всегда передают наружу. Обычный метод берите, когда каждое место вызова может написать `order.add()`.

---

#### Пример

```javascript
import { makeAutoObservable } from "mobx"
class Order {
    amount = 1
    constructor() {
        makeAutoObservable(this)
    }
    add(extra) {
        this.amount += extra
    }
    addOne = () => {
        this.amount += 1
    }
}
const order = new Order()
const onClick = () => order.add(2)
onClick()
// order.amount равен 3
const handler = order.addOne
handler()
// order.amount равен 4
```

`onClick` вызывает `order.add(2)` как метод, поэтому `amount` становится `3`. `addOne` — стрелочное поле. Вызов без объекта впереди всё равно доводит `amount` до `4`.

---

#### Ловушка

Передача ссылки на метод бросает ошибку, и поле остаётся на месте.

```javascript
import { makeAutoObservable } from "mobx"
class Order {
    amount = 1
    constructor() {
        makeAutoObservable(this)
    }
    add(extra) {
        this.amount += extra
    }
}
const order = new Order()
const handler = order.add
handler(2)
// TypeError: Cannot read properties of undefined (reading 'amount')
// order.amount по-прежнему 1
```

`handler(2)` вызывает `add` с `this`, равным `undefined`. Замените эту строку на `const handler = () => order.add(2)` или запишите `add` как стрелочное поле. Тогда `handler()` оставит `amount` равным `3`.

---

#### Сводка

| Что передаёте | `this` внутри метода | Поле после вызова |
|---|---|---|
| `order.add` | `undefined` | Без изменений, `TypeError` |
| `() => order.add(2)` | `order` | Обновлено |
| Стрелочное поле `add = () => { ... }` | Экземпляр | Обновлено |

Передавайте маленькую стрелку, которая вызывает метод, или храните стрелочное поле, когда функцию всегда отрывают. Вызывайте `order.add()` напрямую, когда вызов контролируете вы.

#### Граница инструмента

`this` — это JavaScript, а код класса строгий. `makeAutoObservable` методы не привязывает. Параметр, который их привязывает, — advanced, п. 29.

#### Чем закрыть тему

Передайте метод прототипа функции, которая вызывает его без объекта впереди. Проверьте `TypeError` и неизменное поле. Передайте вместо этого `() => order.add(2)` и проверьте, что поле сдвинулось на `2`.

Уровень base по оглавлению закончен.
