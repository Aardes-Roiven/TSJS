# makeAutoObservable only annotates members that already exist

Детализация п. 16 уровня «base», MobX. Оглавление: [index.md](./index.md).

Конспект: сначала о чём речь и зачем это нужно на этом уровне, потом устройство, пример, ловушка и короткая формулировка, с которой тему можно закрыть.

#### О чём речь

`makeAutoObservable` размечает те поля, геттеры и методы, которые у объекта уже есть в момент вызова. Поле, записанное в объект после вызова, остаётся обычным свойством. Реакция может один раз прочитать его значение и больше не запустится, хотя свойство меняется. Новое поле, добавленное «когда понадобится», выглядит как рабочее состояние и ведёт себя как `let`.

---

#### Модель

Вызов смотрит на объект один раз и раздаёт роли тем членам, которые уже лежат на месте (этот уровень, п. 2). Поздняя запись нового имени роли не получает. Ячейки у этого имени нет. Чтение внутри `autorun` возвращает текущее значение и в список зависимостей его не ставит (этот уровень, п. 11).

У класса инициализаторы полей выполняются до тела конструктора. К строке `makeAutoObservable(this)` поле `label = "a"` уже есть. Присваивание `this.label = "a"` ниже этой строки создаёт свойство, которого вызов не видел.

---

#### Члены, которые вызов застаёт

Поле со значением становится observable state. Геттер становится derivation. Метод становится action. Это те же роли, что в этот уровень, п. 2, и применяются они к списку членов на момент вызова. Поле, объявленное на классе с инициализатором, в этот список входит, даже если метод изменит его позже.

Ключи литерала объекта тоже уже есть: `makeAutoObservable({ amount: 1, label: "a", add() {} })` помечает `amount`, `label` и `add`.

#### Присваивание после вызова

`this.label = "a"` после `makeAutoObservable(this)` создаёт обычное свойство. `order.label` возвращает `"a"`. Следующее `this.label = "b"` меняет его на `"b"`. Реакция, прочитавшая `order.label`, снова не выполняется. Предупреждения о голом присваивании здесь нет: MobX это свойство не наблюдает, проверять action ему не у чего (этот уровень, п. 7).

Метод, который появился на экземпляре после вызова, action не становится. Для полей класса, которые добавляют позже, продолжение — advanced, п. 25.

---

#### Пример

```javascript
import { makeAutoObservable, autorun } from "mobx"

class Order {
    amount = 1
    label = "a"
    constructor() {
        makeAutoObservable(this)
    }
    setLabel(next) {
        this.label = next
    }
}

const order = new Order()
const log = []
autorun(() => {
    log.push(order.label)
})
order.setLabel("b")
// log равен ["a", "b"]
```

`label = "a"` выполняется до тела конструктора. Вызов застаёт поле и помечает его. `setLabel` — метод, который вызов тоже застал, поэтому это action. Лог получает `"b"`.

---

#### Ловушка

То же имя, записанное после вызова, в лог второй раз не попадает.

```javascript
import { makeAutoObservable, autorun } from "mobx"

class Order {
    amount = 1
    constructor() {
        makeAutoObservable(this)
        this.label = "a"
    }
    setLabel(next) {
        this.label = next
    }
}

const order = new Order()
const log = []
autorun(() => {
    log.push(order.label)
})
order.setLabel("b")
// log равен ["a"]
// order.label равен "b"
```

В момент вызова свойства `label` нет. Проход один раз видит `"a"` и зависимости не получает. `setLabel` меняет обычное свойство, лог остаётся `["a"]`. Перенесите `label = "a"` в поле класса, выше `constructor`.

---

#### Сводка

| Когда член появился | Роль после `makeAutoObservable` |
|---|---|
| Поле класса с инициализатором, ключ литерала, геттер, метод | Наблюдаемое поле, derivation или action |
| Присваивание нового имени после вызова | Обычное свойство, реакция его не отслеживает |

Объявляйте поля до вызова. Имя, которое должно обновлять экран, не создавайте первой записью в конструкторе ниже `makeAutoObservable(this)`.

#### Граница инструмента

Список членов собирает MobX в момент вызова. Поле, которое в этот момент не существует как собственное свойство, в список не входит. Так бывает, если компилятор выкинул объявление без инициализатора. Какой флаг это включает — expert, п. 30. Объект, созданный через `observable()`, поздние ключи подхватывает: advanced, п. 24.

#### Чем закрыть тему

Оставьте поле с инициализатором, вызовите `makeAutoObservable(this)` в конструкторе и присвойте поле методом. Проверьте, что лог `autorun` получил новое значение. Перенесите первую запись этого поля под вызов, присвойте снова и проверьте, что лог остался из одной записи, а свойство уже новое.

Уровень base по оглавлению закончен.
