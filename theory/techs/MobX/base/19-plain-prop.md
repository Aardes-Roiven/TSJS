# A value read outside the observer and passed in as a plain prop

Детализация п. 19 уровня «base», MobX. Оглавление: [index.md](./index.md).

Конспект: сначала о чём речь и зачем это нужно на этом уровне, потом устройство, пример, ловушка и короткая формулировка, с которой тему можно закрыть.

#### О чём речь

Число, строка или boolean, переданные пропом, — уже снятое значение. У пропа нет стрелки к полю. Реакция возможна только там, где поле прочитали во время прохода `observer`. Если это чтение стоит снаружи всякой обёртки, не подписан никто: ни родитель, ни ребёнок, даже когда ребёнок обёрнут. Экран держит первое число. Поле читают в том обёрнутом компоненте, который должен перерисоваться, либо в обёрнутом родителе, который передаёт уже новое число вниз.

---

#### Модель

`order.amount` во время прохода заглядывает в ячейку (этот уровень, п. 11). Выражение `amount={order.amount}` снаружи `observer` заглядывает в ячейку один раз и кладёт в проп число, например `1`. Обёрнутый ребёнок видит проп `1`. В поле `amount` его рендер не заглядывает, список пуст. `add` меняет ячейку. Ни родитель, ни ребёнок проход заново не получают.

Тот же проп-число работает, если ячейку прочитал обёрнутый родитель. Родитель перерисовывается и передаёт ребёнку уже `2`. Ребёнок может быть обычной функцией: ему пришло новое число, потому что родителя выполнили снова. Стрелка остаётся у родителя.

Третий рабочий путь — передать сам `order` и прочитать `order.amount` в обёрнутом ребёнке (этот уровень, п. 18). Стрелка тогда у ребёнка. Число снимают как можно позже, в том рендере, который рисует его на экран.

---

#### Чтение снаружи любой обёртки

Функция без `observer`, которая вычисляет `order.amount` и передаёт его в `<Amount amount={...} />`, подписку не создаёт. `observer` на `Amount` подписывается на то, что прочитал рендер `Amount`. Проп `amount` — число. Менять заказ дальше можно сколько угодно: аргумент прошлого вызова уже не связан с ячейкой.

#### Чтение в обёрнутом родителе

`observer` вокруг родителя, и в его рендере написано `amount={order.amount}`. Проход родителя заглядывает в ячейку. `add` выполняет родителя снова. Новый элемент несёт новое число. Ребёнок без `observer` показывает это число, потому что его вызвал родитель, а не потому что ребёнок следит за заказом.

#### Объект вниз, поле в ребёнке

`<Amount order={order} />` передаёт ссылку. Ссылка от `add` обычно та же. Перерисовку даёт чтение `order.amount` внутри обёрнутого `Amount`. Родитель поле может не читать. Это тот путь, которым один заказ доходит до нескольких детей, и каждый следит за своим полем.

---

#### Пример

```jsx
import { makeAutoObservable } from "mobx"
import { observer } from "mobx-react-lite"

const order = makeAutoObservable({
    amount: 1,
    add() {
        this.amount += 1
    }
})

function Amount({ amount }) {
    return <span>{amount}</span>
}

const Page = observer(function Page() {
    return <Amount amount={order.amount} />
})

// первый показ: текст "1"
order.add()
// следующий показ: текст "2"
```

Проход `Page` читает `order.amount`. `add` выполняет `Page` снова, в `Amount` уходит `2`, текст становится `"2"`. `Amount` за полем не следит. Ему хватает нового пропа.

---

#### Ловушка

Единственное чтение поля стоит в функции без `observer`. Обёрнутый ребёнок получает число и больше его не обновляет.

```jsx
import { makeAutoObservable } from "mobx"
import { observer } from "mobx-react-lite"

const order = makeAutoObservable({
    amount: 1,
    add() {
        this.amount += 1
    }
})

const Amount = observer(function Amount({ amount }) {
    return <span>{amount}</span>
})

function Page() {
    return <Amount amount={order.amount} />
}

// первый показ: текст "1"
order.add()
// показ тот же: текст "1"
// order.amount равен 2
```

`Page` читает ячейку вне прохода MobX. `Amount` читает проп `amount`, не поле заказа. `add` никого не будит. Перенесите чтение в обёрнутый `Page`, как в примере выше, либо передайте `order` и читайте `order.amount` внутри `Amount`.

---

#### Сводка

| Где прочитали `order.amount` | Кто обёрнут | Текст после `add` |
|---|---|---|
| В родителе, пропом уходит число | Родитель | Новый |
| В ребёнке, пропом пришёл `order` | Ребёнок | Новый |
| В обычной функции, пропом уходит число | Только ребёнок | Остаётся первым |

На экран отдавайте либо число из рендера обёрнутого родителя, либо поле, прочитанное в обёрнутом ребёнке. Чтение поля в обычной функции пропасом не становится.

#### Граница инструмента

Проп — механизм React. MobX видит только чтения во время прохода `observer`. Число в пропе для MobX то же самое, что `const snapshot = order.amount` до `autorun` (этот уровень, п. 3).

#### Чем закрыть тему

Соберите обёрнутый родитель, который передаёт `order.amount` в обычного ребёнка. Вызовите `add` и проверьте, что текст стал `"2"`. Вынесите это чтение в функцию без `observer`, оставьте `observer` на ребёнке с числовым пропом, вызовите `add` и проверьте, что текст остался `"1"`.

Уровень base по оглавлению закончен.
