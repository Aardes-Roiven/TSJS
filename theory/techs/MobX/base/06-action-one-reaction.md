# Several mutations in one action run one reaction

Детализация п. 6 уровня «base», MobX. Оглавление: [index.md](./index.md).

Конспект: сначала о чём речь и зачем это нужно на этом уровне, потом устройство, пример, ловушка и короткая формулировка, с которой тему можно закрыть.

#### О чём речь

Реакция должна увидеть заказ после правки, а не между строками правки. Один action может присвоить и `price`, и `amount`, и `autorun` выполнится один раз, уже с обоими новыми значениями. Те же два присваивания в двух отдельных вызовах заставят `autorun` выполниться дважды, и в логе появится промежуточная пара. Каждое временное значение тогда становится перерисовкой или запросом. Метод, который собирает записи вместе, — это action (этот уровень, п. 5).

---

#### Модель

Сначала заканчивают жест, потом перерисовывают диаграмму. Две правки внутри одного жеста — одна перерисовка итоговых ячеек. Два жеста — две перерисовки, и диаграмма показывает первый жест раньше второго.

Присваивания внутри текущего action сразу обновляют поля для следующей строки этого action. Реакции ждут, пока action вернётся, и читают поля такими, какими они стали в конце.

---

#### Один метод — один запуск

Оба присваивания в `setBoth` принадлежат одному action. Реакция, которая читает `price` и `amount`, выполняется один раз после возврата `setBoth`. Новая запись лога содержит оба новых числа. Метод, вызванный из `setBoth`, присоединяется к тому же ожиданию. Как `await` разрезает ожидание — expert, п. 3.

#### Метод видит каждую строку

Следующая строка метода читает поле, которое только что присвоила. `console.log` между двумя присваиваниями печатает промежуточную пару. Лог реакции её не печатает. Ждут только реакции.

#### Два вызова — два запуска

`setPrice(8)`, а затем `setAmount(9)`, вызванные снаружи, — это два action. Каждый возврат отпускает реакции. Лог получает пару после смены цены, затем пару после смены количества. Один запуск получается, когда оба присваивания лежат в одном методе и этот метод вызван один раз.

---

#### Пример

```javascript
import { makeAutoObservable, autorun } from "mobx"

const cart = makeAutoObservable({
    price: 1,
    amount: 1,
    setBoth(price, amount) {
        this.price = price
        this.amount = amount
    }
})

const seen = []
autorun(() => {
    seen.push(cart.price + ":" + cart.amount)
})
// seen равен ["1:1"]

cart.setBoth(4, 5)
// seen равен ["1:1", "4:5"]
```

Первая запись — запуск при создании (этот уровень, п. 9). `setBoth` присваивает `price`, затем `amount`. Реакция выполняется ещё один раз. `"4:1"` не появляется. Сам метод между этими строками уже видел бы цену `4` и количество `1`. `seen` эту пару не записывает.

---

#### Ловушка

Соседние вызовы — всё равно два action.

```javascript
import { makeAutoObservable, autorun } from "mobx"

const cart = makeAutoObservable({
    price: 1,
    amount: 1,
    setPrice(price) {
        this.price = price
    },
    setAmount(amount) {
        this.amount = amount
    }
})

const seen = []
autorun(() => {
    seen.push(cart.price + ":" + cart.amount)
})

cart.setPrice(8)
cart.setAmount(9)
// seen равен ["1:1", "8:1", "8:9"]
```

`setPrice` заканчивается, и лог записывает `"8:1"`. `setAmount` заканчивается, и лог записывает `"8:9"`. Перенесите оба присваивания в один метод, как в `setBoth`, и лог за один шаг перейдёт от `"1:1"` к `"8:9"`.

---

#### Сводка

| Вызов | Дополнительных запусков реакции | Что записывает реакция |
|---|---|---|
| `setBoth(4, 5)` | Один | `4:5` |
| `setPrice(8)`, затем `setAmount(9)` | Два | `8:1`, затем `8:9` |

#### Граница инструмента

Ожидание относится к реакциям MobX. Строки внутри метода идут по порядку и сразу видят каждое новое значение поля.

#### Чем закрыть тему

Логируйте `price` и `amount` из одного `autorun`. Вызовите метод, который присваивает оба, и проверьте, что лог получил одну запись с обоими итоговыми числами. Вызовите вместо этого два метода и проверьте, что между ними появилась промежуточная пара.

Уровень base по оглавлению закончен.
