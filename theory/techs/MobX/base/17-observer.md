# observer

Детализация п. 17 уровня «base», MobX. Оглавление: [index.md](./index.md).

Конспект: сначала о чём речь и зачем это нужно на этом уровне, потом устройство, пример, ловушка и короткая формулировка, с которой тему можно закрыть.

#### О чём речь

`observer` превращает рендер функционального компонента в проход, который записывает прочитанные поля. Когда action меняет такое поле, React рисует компонент снова. Без обёртки компонент — обычная функция React: она видит `order.amount` один раз и о новом значении не узнает. Экран остаётся на первом числе, хотя заказ уже другой. Обёртка берётся из пакета `mobx-react-lite`. Сам заказ по-прежнему размечает `makeAutoObservable`.

---

#### Модель

Рендер обёрнутого компонента — та же диаграмма, что `autorun` (этот уровень, п. 9). Пока React выполняет функцию компонента, чтения полей попадают в список (этот уровень, п. 11). Законченный action, который эти поля изменил, просит React выполнить функцию ещё раз. Новый проход заново собирает список.

Обёртка не запускает рендер сама по себе и не копирует store. Она связывает один проход рендера с полями, которые этот проход прочитал. Компонент, который поле не читал, из-за присваивания этого поля заново не выполняется.

---

#### Обёртка вокруг одной функции

`observer(function View() { ... })` возвращает компонент, который кладут в дерево как `<View />`. Внутри функции читают `order.amount` прямо в том значении, которое попадёт на экран. Первый проход показывает текущее число. `order.add()` меняет поле, функция выполняется снова и показывает новое.

Читать можно поле, пришедшее пропом, и поле из замыкания. Для списка зависимостей важно, что чтение случилось во время этого рендера. Откуда взялась ссылка на заказ, списку всё равно.

#### Поле, которое рендер не прочитал

Функция может замыкать `order` и при этом не заглянуть ни в одно поле: вернуть постоянную строку или упомянуть объект, не читая `amount`. Список пуст по этому полю. `add` число на экране не меняет. Доступность заказа из модуля подпиской не является.

Дочерний компонент эта обёртка не размечает. Кто обязан быть обёрнут, если поле читает ребёнок, — этот уровень, п. 18.

---

#### Пример

```jsx
import { makeAutoObservable } from "mobx"
import { observer } from "mobx-react-lite"

const order = makeAutoObservable({
    amount: 1,
    add() {
        this.amount += 1
    }
})

const View = observer(function View() {
    return <span>{order.amount}</span>
})

// первый показ View: текст "1"
order.add()
// следующий показ View: текст "2"
```

`View` во время рендера читает `order.amount`. Первое число на экране — `1`. `add` пишет поле из action. React вызывает `View` снова, и текст становится `"2"`. Отдельный `autorun` для этой перерисовки не нужен.

---

#### Ловушка

Обёрнутый компонент, который поле не читает, после `add` показывает ту же строку.

```jsx
import { makeAutoObservable } from "mobx"
import { observer } from "mobx-react-lite"

const order = makeAutoObservable({
    amount: 1,
    add() {
        this.amount += 1
    }
})

const View = observer(function View() {
    return <span>заказ</span>
})

// показ: текст "заказ"
order.add()
// показ тот же: текст "заказ"
// order.amount равен 2
```

`observer` на функции уже есть. Рендер в `amount` не заглядывает, поэтому `add` новый проход не заказывает. Текст, который должен меняться, берите из поля внутри этой функции: `{order.amount}`.

---

#### Сводка

| Рендер обёрнутого компонента | Что делает `add`, меняющий `amount` |
|---|---|
| Прочитал `order.amount` | Компонент выполняется снова и показывает новое число |
| Поле не читал | Текст остаётся прежним, поле уже новое |

Оборачивайте компонент, который рисует данные заказа, и читайте поле в том выражении, которое попадает в разметку.

#### Граница инструмента

`observer` живёт в `mobx-react-lite` и просит React выполнить функцию компонента снова. Список чтений ведёт MobX, тем же правилом, что у `autorun`. Обёртка классового компонента приходит из другого пакета: advanced, п. 47.

#### Чем закрыть тему

Оберните компонент в `observer`, выведите `order.amount` и вызовите `add`. Проверьте, что текст сменился с `"1"` на `"2"`. Уберите чтение поля, оставьте постоянную строку, вызовите `add` снова и проверьте, что текст прежний, а `order.amount` уже увеличился.

Уровень base по оглавлению закончен.
