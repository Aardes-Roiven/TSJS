# A read inside an event handler does not subscribe

Детализация п. 20 уровня «base», MobX. Оглавление: [index.md](./index.md).

Конспект: сначала о чём речь и зачем это нужно на этом уровне, потом устройство, пример, ловушка и короткая формулировка, с которой тему можно закрыть.

#### О чём речь

Обработчик клика выполняется, когда проход рендера уже закончился. Поле, прочитанное в `onClick`, в список компонента не входит. Клик видит значение на момент клика. Присваивание этого поля компонент заново не рисует, если рендер сам поле не читал. Кнопка показывает первое число, хотя обработчик при клике прочитал бы уже новое. Текст на кнопке берут из чтения в рендере. В обработчике поле читают, чтобы среагировать на клик, а не чтобы подписаться.

---

#### Модель

Рендер `observer` — проход диаграммы (этот уровень, п. 17). `onClick` React вызовет позже, отдельным вызовом. Это то же правило, что у `setTimeout` после `autorun`: чтение после возврата из отслеживаемой функции в её список не записывается (этот уровень, п. 11).

К моменту клика чтение `order.amount` возвращает текущее число. Это обычное чтение вне реакции. Оно не заказывает следующий рендер и не продлевает прошлый.

Поле, которое стоит в разметке, `{order.amount}`, читается во время рендера. Его присваивание рисует компонент снова. У одной кнопки два разных чтения: подпись из рендера и значение, снятое в момент клика.

---

#### Чтение в обработчике

`() => { clicked = order.amount }` выполняется по клику. В список рендера `amount` от этого не попадает. Если подпись кнопки это поле не читает, `add` подпись не меняет. Клик после `add` снимает уже новое число в переменную `clicked`. Экран от этой записи сам не обновляется: `clicked` — обычная переменная.

Обработчик может вызывать action: `onClick={() => order.add()}`. Вызов меняет поле. Подписку создаёт не вызов, а чтение поля в рендере того компонента, который должен показать результат.

#### Чтение в разметке

Текст кнопки — часть возвращаемого элемента. Вычисление `order.amount` здесь происходит, пока React выполняет функцию компонента. Проход записывает поле. Следующий `add` выполняет компонент снова, и подпись показывает новое число. Обработчик при этом может читать другие поля или не читать ничего.

Чтение в `useEffect` тоже стоит вне рендера. Этот случай — advanced, п. 49.

---

#### Пример

```jsx
import { makeAutoObservable } from "mobx"
import { observer } from "mobx-react-lite"

const order = makeAutoObservable({
    amount: 1,
    label: "черновик",
    add() {
        this.amount += 1
    },
    retitle(label) {
        this.label = label
    }
})

const Button = observer(function Button() {
    return (
        <button onClick={() => order.add()}>
            {order.label}
        </button>
    )
})

// первый показ: текст "черновик"
order.add()
// показ тот же: текст "черновик"
// order.amount равен 2

order.retitle("готов")
// следующий показ: текст "готов"
```

Рендер читает `label`, поэтому `retitle` меняет подпись. `onClick` только вызывает `add`. Поле `amount` рендер не читает, и смена `amount` кнопку заново не рисует. На кнопке по-прежнему текст про `label`.

---

#### Ловушка

Единственное чтение `amount` спрятано в `onClick`. Подпись собрана из обычной переменной и после `add` не меняется.

```jsx
import { makeAutoObservable } from "mobx"
import { observer } from "mobx-react-lite"

const order = makeAutoObservable({
    amount: 1,
    add() {
        this.amount += 1
    }
})

let clicked = 0
const Button = observer(function Button() {
    return (
        <button onClick={() => { clicked = order.amount }}>
            {clicked}
        </button>
    )
})

// первый показ: текст "0"
order.add()
// показ тот же: текст "0"
// order.amount равен 2
// clicked равен 0, пока по кнопке не нажмут
```

`clicked` в разметке — не поле заказа. `order.amount` назван только в обработчике, поэтому `add` рендер не заказывает. Покажите `order.amount` прямо в кнопке: `{order.amount}`. После `add` текст станет `"2"` ещё до клика.

---

#### Сводка

| Где прочитано поле | Когда видно значение | Заказывает ли новый рендер |
|---|---|---|
| В разметке обёрнутого компонента | На каждом рендере после изменения поля | Да |
| В `onClick` | В момент клика | Нет |

Подпись и остальные видимые данные читайте в теле рендера. В обработчике вызывайте action и снимайте значение, только если оно нужно этому клику.

#### Граница инструмента

Поздний вызов обработчика делает React. MobX проход рендера на `onClick` не продлевает. Правило то же, что у любого чтения после возврата из отслеживаемой функции.

#### Чем закрыть тему

Покажите в обёрнутой кнопке одно поле, а второе читайте только в `onClick`. Измените первое и проверьте, что подпись обновилась. Измените второе и проверьте, что подпись прежняя. Перенесите второе поле в подпись и проверьте, что теперь обновляются оба.

Уровень base по оглавлению закончен.
