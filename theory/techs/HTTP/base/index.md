6. Status line: status code and reason phrase
7. Header field names, values, and the blank line
8. GET, HEAD, POST, PUT, PATCH, DELETE, and OPTIONS
9. Safe and idempotent methods
10. 200, 201, and 204
11. 3xx and the Location header
12. 400, 401, 403, 404, and 405
13. 500, 502, 503, and 504
14. Content-Type and the message body
15. Content-Length
16. The Host header
17. Query string and application/x-www-form-urlencoded
18. multipart/form-data
19. Set-Cookie and the Cookie header
20. The Authorization header
21. https and the default ports
22. Persistent connections in HTTP/1.1
